- 模型为 MuJoCo Menagerie Panda `scene.xml`，提交 `98a70c569c4c1b6da467a20012f766ee1f8dc521`；本机检出 HEAD 已核对，工作树无改动。Windows，MuJoCo 3.17.0、NumPy 2.5.4。
- 每个样例均从 `home` 关键帧开始求解；七个臂关节角为 `(0, 0, 0, -1.57079, 0, 1.57079, -0.7853)` rad。两夹爪关节位置均为 0.04 m。

- 目标和 FK 回代位置均为 `link0` 坐标系下的 `hand` 原点，单位 m；结果不包含姿态、碰撞或运动轨迹验证。阻尼 0.02，单步每轴最多 0.15 rad，最多 150 次迭代，位置误差不超过 0.0001 m 判收敛。

## 复现

在仓库根目录使用 Windows PowerShell；模型和 Python 依赖准备见 [项目 README](README.md#在本机复现)。输出文件须不存在。下列命令仅运行几例固定 IK，不训练，也不使用随机种子。

```powershell
$py = (Join-Path $env:USERPROFILE 'Documents/ChatGPT/EIP/.venv-panda-sac-cpu/Scripts/python.exe')
$scene = Join-Path $env:LOCALAPPDATA 'EmbodiedAI/PandaSmoke/menagerie-98a70c5/franka_emika_panda/scene.xml'
$ik = 'hands-on-reinforcement-learning/15_RobotSystem/panda_ik.py'
$out = (Join-Path $env:USERPROFILE 'Documents/ChatGPT/EIP/ik-repro.json')
& $py $ik $scene --smoke --output $out
```

五个样例的目标由脚本固定生成：home 及 home 加关节偏移 `(0.20,-0.18,0.10,0.15,0,0.10,0)`、`(-0.22,0.16,-0.12,-0.20,0.08,0,0)` rad 后的 FK 位置，另有远目标 `(3,0,3)` 和限位样例 `(0,0,-3)` m。每次求解初值仍是 home，而非生成目标的偏移姿态。可分别用 `--goal X Y Z` 指定目标；非收敛时程序输出诊断并以非零码退出，`--output` 仍保存结果。
