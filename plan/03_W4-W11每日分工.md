# W4 至 W11 每日分工

主线以 [作战计划 v8](00_作战计划.docx) 和 [工程验收](11_工程主线验收.md) 为准。每周按周一至周六各一个 3 小时个人工作块安排，周日休息或替换本周某一天。个人操作、学习、求职和缓冲合计不超过 18 小时，agent 后台工程和机器运行时间单独记录。

Agent 在本人开始依赖其结果的练习前，交付代码、运行方式、短测试结果和已知阻塞。在聊天中实际安排执行，日期本身不代表自动启动。个人练习中的命令、预测和观察由本人完成并记录；agent 可以指导和排障。若前置交付没有完成，先完成当天不依赖它的部分，将其余内容放入本周缓冲。

## W8–W11 的每周六个工作块

适用于 W8（12/14–12/20）、W9（12/21–12/27）、W10（12/28–2027/1/3）和 W11（1/4–1/10）。每周依照实际面试和岗位反馈更新具体公司及日期；1/11–1/15 沿用以下工作块，计入所属自然周预算。投递、联系与提交由本人决定并执行。

| 工作块 | Agent 工作及交付 | 本人 3 小时 |
| --- | --- | --- |
| 周一 | 查公开岗位并区分新旧招聘信息，标记待核验条件。 | 核验 3h，筛选职责、到岗、出勤和通勤。 |
| 周二 | 按本人提供的真实经历整理面试题与材料。 | 项目模拟面试 3h。 |
| 周三 | 整理可验证的问题与针对性修复方案。 | 1h 必要修复或复现，2h 岗位准备。 |
| 周四 | 整理岗位和材料，不代发信息。 | 3h 本人选择投递、跟进或准备面试。 |
| 周五 | 汇总本人面试后的技术问题及资料入口。 | 2h 面试复盘，1h 岗位核验。 |
| 周六 | 整理下周待办与证据状态。 | 3h 周缓冲、待补事项或休息。 |

周三最多 1h 为必要工程修复，全周工程上限与原 W8 预算兼容。具体面试占用替换相应工作块；不把个人实践、投递或口述标成 agent 已完成。
