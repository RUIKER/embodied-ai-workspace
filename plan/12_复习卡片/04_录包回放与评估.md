# 录包回放与评估

> 固定轨迹的 MCAP 录制、状态回放和命令重执行均已通过冒烟。状态回放核对已有记录，重执行比较新产生的物理轨迹。见 [冒烟结果](../../hands-on-reinforcement-learning/15_RobotSystem/README.md#固定输入与结果)。

## 1. 录什么，怎么回放

录轨迹命令、`JointState` 和 `/clock`，用 `ros2 bag info <bag>` 检查话题类型、消息数和时长。配置旁路记录保存模型 SHA、初态、控制周期、步长、QoS 和测试场景。bag 的记录时间与消息的 `header.stamp` 分开理解。若 recorder 启用 `--use-sim-time`，确认收到首个 `/clock` 后再开始测试。见 [rosbag2 Humble 文档](https://raw.githubusercontent.com/ros2/rosbag2/humble/README.md)。

| 模式 | 做法 | 可观察的证据 |
| --- | --- | --- |
| 状态回放 | 关闭实时发布器，仅回放记录。播放记录中的 `/clock` 或由播放器生成时钟，选一个来源。 | 状态可读取，离线图和误差表可从记录重建。 |
| 命令重执行 | 按原配置重置仿真，仅重放轨迹命令，保留实时仿真 `/clock`。让命令起点对齐新一轮仿真时间，明确非零 `header.stamp` 的转换或拒绝规则。 | 新产生的状态轨迹与原运行的差异。 |

## 2. 怎么算和怎么解释

按关节名匹配。在每个有效状态时间戳 `t_i`，按执行端同一规则插值得到 `q_ref(t_i)`，再算 `e_i = q_meas(t_i) - q_ref(t_i)`。跨 reset 分段，缺测或超出参考范围的点单独记录。

| 指标 | 定义与含义 |
| --- | --- |
| 跟踪 RMSE | `sqrt(mean(e_i^2))`，按关节报告全程误差。 |
| 峰值误差 | `max(abs(e_i))`，定位最差时刻。 |
| 稳态误差 | 预先固定保持窗口和统计方式，例如窗口内平均绝对误差，和末帧误差分开报告。 |
| 实际发布率与间隔 | 记录测量时间域，分别报告有效样本数、频率、间隔分位数和缺测。只凭消息数差异，无法归因到发布、传输或录制中的某一层。 |

正式评估前固定轨迹、起点、次数、窗口和阈值。测试集合与应留存的证据见 [工程验收](../11_工程主线验收.md)。

## 3. 自测

- **故障定位**。回放后状态时间戳忽快忽慢，先查 `/clock` 是否有多个来源，再核对 `use_sim_time`、bag 时间与消息时间、reset 分段。
- **面试追问**。同一个 bag 回放两次得到完全相同的图，说明哪一层可以复现？若要检验动力学重执行，还要保存和对齐哪些输入？
