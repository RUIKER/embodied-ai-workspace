# VLA 基础

> Vision-Language-Action 策略根据视觉观测和语言指令预测机器人动作。这里用于原理复习，当前项目实践覆盖 BC 和 Panda 独立仿真。

## 1. 输入到动作

例如观测是桌面图像，指令是“把红色方块放进盒子”。视觉提供物体和场景信息，语言指定对象与目标。模型根据这些条件输出动作，有些模型也输入关节状态等本体感知信息。动作还要按训练时的坐标系、单位、归一化和动作频率转换，才能交给机器人接口。

| 例子 | 动作表示 |
| --- | --- |
| OpenVLA 原版 | 把连续动作各维离散为 token，预测后解码回动作。见 [OpenVLA 论文第 3.2 节](https://arxiv.org/html/2406.09246v3#S3.SS2)。 |
| π₀ | 在预训练视觉语言模型基础上，用 flow matching 生成连续动作块。见 [π₀ 论文第 IV 节](https://arxiv.org/html/2410.24164v4#S4)。 |

## 2. 与 BC、ACT、Diffusion Policy 怎么接

- **BC** 回答监督信号从哪里来，用示范的观测和动作训练策略。VLA 可以同样从示范学习，只是把视觉与语言纳入条件，并选择合适的动作表示。
- **ACT** 用 action chunking 预测一段动作，用 CVAE 建模示范中的动作变化。**Diffusion Policy** 通过条件去噪生成动作序列。两者可用于理解 VLA 动作输出的设计，具体模型的输入条件和训练目标仍需逐个核对。
- **工程主线**从关节轨迹命令开始验证。未来接学习策略时，先明确它输出的是末端位姿增量、关节位置还是其他动作，再核对坐标系、转换、限位和执行周期。

原卡见 [BC](../../hands-on-reinforcement-learning/13_Imitation/算法卡片_BC.md)、[ACT](../../hands-on-reinforcement-learning/13_Imitation/算法卡片_ACT.md) 和 [Diffusion Policy](../../hands-on-reinforcement-learning/13_Imitation/算法卡片_DP.md)。

## 3. 自测

- **预测故障**。指令和图像都正确，机械臂仍朝反方向运动。按动作反归一化、基座与末端坐标系、单位、关节映射和低层执行日志逐层定位。
- **面试追问**。同一张桌面图像，指令从“拿红块”改为“拿蓝块”，希望动作如何变化？如何用固定场景、不同指令和闭环任务成功率验证语言是否影响行为？
